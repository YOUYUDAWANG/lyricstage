# LyricStage contracts

The JSON schemas in `schemas/` and conformance fixtures in `fixtures/` are the portable interchange surface for independent clients such as BiliMusic.

Those two directories are available under your choice of `Apache-2.0 OR AGPL-3.0-only`. TypeScript runtime and validation code under `src/` remains covered by the repository's `AGPL-3.0-only` license. Consumers should copy a fixed version, record the source commit and file hashes, and avoid a live Git submodule dependency.
